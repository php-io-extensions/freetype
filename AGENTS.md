# Agent guidance — php-io-extensions/freetype

1. **Read [`.okf/index.md`](.okf/index.md) first** before changing the API, the C, or packaging. Open only the concepts the change touches.
2. **FreeType, 1:1, at the 2.13.2 API.** One PHP function = one FreeType function, under its C name and signature, every C parameter its own PHP parameter in C order. Constants are the C constants, registered with `@cvalue`; not class constants, not enums. No defaults the C call lacks, no composites, no conveniences. Nothing newer than 2.13.2: the gaming PC's FreeType is 2.13.2, so a newer symbol fails its build. FreeType's behaviour passes through: error codes, NULL and odd but documented results reach PHP as FreeType produces them. See [`.okf/api/bindings.md`](.okf/api/bindings.md).
3. **Refusals.** The rule, verbatim:
   > A refusal is the extension declining to make the native call. The extension may refuse only when making it would cause (1) memory unsafety — the call would dereference a native object the PHP wrapper no longer validly references; (2) uncatchable process death — SIGSEGV, SIGBUS, abort(), or an ObjC/C++ exception unwinding through Zend frames; (3) VM corruption — PHP code run on a non-PHP thread or illegal engine re-entry. Nothing else justifies a refusal: return codes, nil, clamping, logs, odd but documented results pass through. Every refusal needs a probe on a real build for that exact call. Translation (an NSException AppKit raised, after the native call, turned into AppKitException) is not a refusal. A need of code built on the extension is solved in that code, not here.

   FreeType has no error object to translate: its error codes are return values. A released handle holds NULL and FreeType checks NULL itself, so a released handle passes through to FreeType.
4. **Glue** is the only native code beyond the calls: handle boxing and release, the record readers behind handle properties, struct copies in and out, and the persistent copy of a memory face's bytes, freed by the face's `FT_Generic` finalizer. Each forwards what FreeType gives and adds nothing else.
5. **Translations.** An out-parameter is by reference in native position (`?FT_Face &$aface`), `null` when the call fails. `const char *` is `string`. Integer typedefs and enums are `int`. A struct is a `final` class with one typed public property per C field, in field order, under the C name, zero by default, no constructor; a `char` array field is its bytes, another array field a list of ints, a pointer field an `int` address. See [`.okf/architecture/structs.md`](.okf/architecture/structs.md).
6. **The guard.** ext-guard checks every edit to this repo in Claude Code, Cursor and the git hooks. If it blocks an edit, fix the edit; never route around it. `bindings.json` sections: `symbols` — an agent may add entries, validated against the FreeType headers; `glue`, `helpers`, `sites` and `typemap` — only the maintainer (Angel) edits them. A throw on an added line needs a `/* binding:<id> */` marker naming a site, unless it sits inside a `helpers.marshal` function. One marker marks one line.
7. **A kept refusal** reads `if (!PHPFT_PROBE_OFF("<id>") && (<check>))`, carries `/* binding:<id> */` on its throw line, has its `sites` entry in `bindings.json`, and a probe test in `tests/Probes` that shows the crash with the check off (`ftChild()` in `tests/Pest.php`). Probe builds use `FREETYPE_CONFIGURE=--enable-freetype-probes`; in that build env `PHPFT_PROBE_OFF=<id>` turns one site's check off and the constant `PHPFT_PROBES` exists. Probe tests skip on release builds. Never ship a probe build.
8. **Handles.** `final`, private empty `__construct`, not cloneable, not serializable, `pointer(): int`, `static fromPointer(int $pointer): static`. One PHP object per native pointer per thread (`phpft_box`, module global `boxes`). A child handle (a face's size, glyph slot and outline; a library's faces) is released with its parent. Dropping a PHP object never calls `FT_Done_*`. See [`.okf/architecture/handles.md`](.okf/architecture/handles.md).
9. **The stub is the declaration.** Edit `stubs/*.stub.php`, regenerate with `php84 /opt/homebrew/opt/php@8.4/lib/php/build/gen_stub.php stubs`, commit both. Never hand-edit `*_arginfo.h`. One `src/<Group>.c` per stub registers that stub's functions and classes; `config.m4` lists the sources.
10. **Build.** Mac: `bash install-macos.sh` into Homebrew `php@8.4` (`php84`) and `php@8.4-zts` (`zhp`). Linux: `bash install-debian-trixie.sh`. Both fail on a warning from `src/`. Pest v4 at `-d memory_limit=128M`, `XDEBUG_MODE=off`. Run the test files a change touches; gate a commit on the run's exit code. See [`.okf/runbooks/build.md`](.okf/runbooks/build.md).
11. **Durable facts go in `.okf`.** Update the matching concept, bump its `generated.at`, append `.okf/log.md`. The bundle documents the package, never a session.
12. **Version** is `PHP_FREETYPE_VERSION` in `php_freetype.h`: 0.11.0. It moves only past a published tag; tags drive Packagist. `os-families`: linux, darwin.
